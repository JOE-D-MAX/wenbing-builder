# 一键随机配置 1–10 页网站

在模块搭建工作台的“组合页面”区域，网页版式下方使用“随机配置”。

默认选择“整个网站”，在“网页数量”输入框填写 1–10 的整数（默认 7），点击“一键配置整站”后实际页数严格等于输入值，页面菜单旁显示“共 X 页”。空值、小数或超出范围的输入会提示修正，不修改项目。从上方“当前页面”菜单切换编辑，进入“预览”可体验站内跳转。

随机配置区域新增“统一配色”开关，默认关闭。关闭时，整站共享底色、辅助底色与文字色，特效强调色按区块变化；即使是固定随机种子，多个区块也不会全部采用相同强调色。开启后展开整站调色盘，可以选择预设，或分别修改底色、辅助底色、文字和特效颜色，修改即时应用到所有原生区块。关闭开关会保持底色、重新分配特效色。

配色模式和自选颜色随草稿保存，开关及调色均可撤销、恢复；导入 HTML 保留自身设计。调色不更换特效类型、背景样式、视频或作者内容。开启统一模式时，之后的随机配置、新增及复制区块也会继续使用指定颜色；右侧颜色输入和拖入配色素材同步整站，背景类型仍按原来的区块或页面范围修改。调色方案的开源核查见 `vendor/color-controls-research.md`。

## 在“组合页面”同时查看全部网页

随机生成的网页直接显示在原有三栏工作台中间的“组合页面”，位于随机配置按钮下方，左侧素材与右侧属性栏保留。所有 1–10 个独立网页使用原有完整编辑区块，从上到下连续展开。页头显示页码、名称及区块数量；点击任意页的区块即可编辑该区块，不需要进入额外界面。

已有内容后不再插入“添加下一块内容”的空白面板，画布末尾的“添加空白区块”按钮及右下角加号均已移除。页面与区块外部间距收紧，保持纵向连贯；真正没有内容的页面保留紧凑的拖入素材提示。

画布选中和拖入时不再显示蓝色外框，以工具条灰底和“编辑中”文字提示当前操作对象。背景库移除细线网格，随机配置也不会再选到网格；旧草稿中的网格显示为原来的纯色底色，保留文字、颜色与其他内容，预览和导出保持一致。

点击配置后自动定位到原有纵向画布。上方“当前页面”菜单可以定位到对应网页；新增或删除页面也会定位到当前保留页面。编辑/互动预览切换会定位到对应内容。撤销/恢复时画布与总数同步更新；页面选择及定位不产生新的撤销记录。界面遵循系统减少动画设置。

每页都保留原有背景、配色、图片、特效演示和编辑操作，可将素材直接拖入所属页面。复制、删除、排序及图片/视频上传均作用于对应网页。已有区块仅支持在所属网页内排序，跨页拖动会给出提示。动效和视频继续使用原有可见性检测、暂停演示与减少动画支持；导入 HTML 及站内跳转可在原有互动预览中体验。

- 为空白页面和新增页面安排通用的可编辑内容、布局和导航，同时随机搭配整站配色、背景及动效。
- 数量减少时保留前面的页面及其文字、图片、视频和名称，移除后面的页面，并修复指向已移除页面或区块的内部跳转。数量增加时补齐新页面；项目页面上限为 10。
- 如果当前正在编辑的页面被移除，会自动显示保留的第一个页面。整次操作可用一次撤销恢复，包括被移除页面和原有跳转。
- 只有一页时，末尾按钮跳转到本页内容；多页时可跳转到下一页。第 9、10 页提供“资源”和“动态”的可编辑内容。
- 相同数量再次点击会重新搭配样式，不会重复添加同一套页面、导航或区块。
- 鼠标追光只参与首页和尾页的随机搭配，每个符合条件的区块有 15% 的生成概率；中间页不生成，导航也不再默认带追光。调整网页数量后按新的首尾位置判断；只有一页时，该页可以低概率生成追光。当前页面和选中区块的随机配置遵循同样的位置限制，手动添加特效不受影响。
- 整站配置作为一次操作，可以一次撤销、恢复，并通过原有草稿流程自动保存。无需 API Key。
- 新内容跟随生成时的中文或英文界面，后续切换语言不会改写已经生成或编辑的内容。

也可以把“配置范围”切换为局部调整：

- 选择“当前页面”：本页可编辑区块共享底色；特效色根据“统一配色”开关采用随机强调色或指定的统一颜色，分别搭配适用背景与动效。
- 选择“选中区块”：仅改变当前选中的可编辑区块。
- 空白页会创建一个空白风格区块，之后可以继续填写内容。
- 再点击一次会更换搭配；每次操作都可分别撤销、恢复，并通过原有草稿流程自动保存。
- 局部调整保留文字、图片、链接、区块顺序和其他页面；已有视频背景继续使用原视频。导入网页保留自身样式。
- 没有图片时不选择图片放大，浅色背景不选择星空；沿用现有的暂停演示与减少动态效果支持。
- 中英文界面均支持，手机上可通过“页面画布”进入同一操作区。

此版本包含此前的草稿覆盖、HTML 导航、跨页撤销和首页文案修复。

运行方式见 README。代码包只包含源码，先运行 `npm ci`，再运行 `npm run dev -- --hostname 127.0.0.1 --port 3000`。
