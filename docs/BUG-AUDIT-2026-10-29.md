# Bug audit — 2026-10-29

This pass fixes six reproduced issues without adding dependencies or changing the editor workflow.

## Fixed issues

1. **Template drafts could overwrite newer work from another tab.** The template studio saved its captured draft on mount and `pagehide`, even when it had no local edits. It now uses the existing conflict-aware persistence controller. Only pending edits are saved; conflicting drafts remain downloadable, leaving with unsaved changes warns the user, storage failures can be retried, and in-app navigation flushes pending edits. Legacy drafts and explicitly selected examples remain supported.
2. **API quick-fill presets sent the wrong provider profile.** The UI always submitted `custom`, bypassing the existing provider-specific request options. A selected preset now uses its provider profile only while its endpoint matches the original preset. Edited endpoints and custom mode keep the user's endpoint and model. No automatic retry or paid test request was added.
3. **Empty pages ignored saved unified colors in preview/export.** Outer-page colors now come from the first native block, falling back to the enabled project palette for empty/import-only pages. An imported HTML block cannot override a native page's surrounding colors.
4. **Background videos could stop recovering after rapid visibility changes.** An older rejected `play()` promise could mark a newer playback attempt as blocked. Playback requests now have generations so stale failures cannot disable a newer attempt. Real autoplay denial, manual pause, reduced-motion and offscreen pausing remain supported.
5. **Some custom accent colors produced low-contrast button labels.** Automatic foreground selection previously treated `#090909` as pure black. It now compares the actual foreground contrast and uses a pure-black fallback in the narrow range where needed. This changes the automatic label color only, not the user's chosen palette.
6. **Long titles containing emoji could be truncated into broken characters.** Generated navigation labels and parsed model text now avoid leaving an unmatched high surrogate at a truncation boundary. Existing length limits remain unchanged.

## Verification

- Each issue has a regression case in an existing test script; the template overwrite, API preset, empty-page color and video race cases were observed failing before their fixes.
- `npm test`: 16 scripts passed, including real UI callbacks/hooks, offline API requests, storage, renderer/runtime behavior, random generation and media handling.
- `npm run typecheck`: passed.
- `npm run test:i18n`: 7 dictionaries, 799 messages passed.
- `npm run build`: passed.
- `node scripts/test-http.mjs http://127.0.0.1:4177`: passed. Block, template and API studio routes return HTTP 200; each served client bundle matches the new build byte for byte.
- `npm run lint` is not a passing check: this source tree has no ESLint 9 flat configuration. A read-only check with the installed Next.js presets also reports existing rule violations. This pass did not suppress those rules or undertake a broad lint migration.
- Browser automation is disabled in Work settings. These checks do not claim visual browser or physical-phone verification. API compatibility tests use offline mocks and do not verify a live paid account.
