# 修复说明 · 2026-10-29

此版本基于用户提供的 `wenbing-builder-source.zip`，修复检查报告中的四处问题。

## 修复内容

1. 模块编辑器：已经保存且没有新修改的旧标签页离开时不再重写草稿；保存前检查已有草稿是否变化。发现其他标签页更新时暂停本页保存，显示中英双语提示，并提供下载当前副本和重新加载最新草稿的操作。待保存修改遇到存储失败或冲突时会保留在页面内存；离开页面时尝试保存，仍未保存则提示。下载副本是项目 JSON 留存文件，当前界面没有项目 JSON 导入入口。
2. 模板下载：接口保留原始 HTML，仅预览窗口转换 iframe 链接。下载文件的“菜单、关于、联系、返回顶部”等入口使用当前网页的区块地址。
3. 跨页撤销：页面名称的编辑分组包含页面 ID；切换页面结束当前输入分组。一次撤销不再连带还原另一页面名称。
4. 首页文案：中文和英文均改为下载 HTML 后自行部署，移除付款后领取公开网址的错误说明。

没有新增依赖。保留原有草稿格式及存储键，不需要迁移已有项目。

## 运行

解压源码包后进入 `wenbing-builder` 文件夹。需要 Node.js 24.19 或更新的 24.x 版本。

```sh
npm ci
npm run dev -- --hostname 127.0.0.1 --port 3000
```

打开 `http://127.0.0.1:3000`。此包只包含源码，依赖和构建目录不打包。
